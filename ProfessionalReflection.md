## **Growth Through Coursework and the ePortfolio**

Completing my coursework and building this ePortfolio gave me the opportunity to revisit, enhance, and document key artifacts that represent my evolution as a computer science major. Through this process, I strengthened my technical problem-solving, debugging, and architectural design skills. I was able to do this while improving code readability, maintainability, and security.

For example, in CS-405: Secure Coding, I applied SEI CERT C++ Coding Standards to refactor vulnerable source code, eliminating unsafe memory practices, implementing robust input validation, and making sure of proper resource deallocation. This work increased my awareness of secure software principles such as least privilege, defense in depth, and input sanitization.

In CS-340: Client/Server Development, I created a full-stack Animal Shelter Dashboard that integrates Python, Dash, and MongoDB to manage animal records. For my ePortfolio, I expanded this project into a more modular, secure application by refactoring it into four components. These are data.py, layout.py, callbacks.py, and app.py. I did this to improve scalability and maintainability. I strengthened database security by replacing hardcoded credentials with environment variables, validating CRUD inputs, and adding role-based access control.

Lastly, my OpenGL 3D Graphics Engine project, developed earlier in the program became a platform to demonstrate software design and algorithmic optimization. During enhancement, I encapsulated global pointers into an ApplicationManager class to improve modularity, replaced inefficient O(n²) collision detection with a quadtree spatial partitioning algorithm, and added Doxygen documentation for clarity and maintainability. These enhancements reflect professional-level refactoring that improved performance and scalability qualities highly relevant to real-time rendering and game development.

## **Integration of Artifacts**

The artifacts within my ePortfolio demonstrate how my knowledge changed across the computer science disciplines and how each enhancement reflects intentional, professional improvement.

### - Category 1 Software Design & Engineering : Animal Shelter Dashboard 

This artifact was originally created in CS-340, this full-stack web application uses Python, Dash, and MongoDB to manage animal records. For my enhancement, I refactored the design into modular components that consist of data.py, layout.py, callbacks.py, and app.py to improve scalability and readability. I also integrated secure coding practices by moving credentials to environment variables, adding input validation for CRUD operations, and enforcing role-based access control. These improvements highlight my ability to design secure, maintainable database applications that align with professional standards.

### - Category 2 Algorithms & Data Structures: OpenGL 3D Graphics Engine

This project demonstrates my ability to apply algorithmic design to real-time rendering systems. I enhanced the original code by encapsulating global state into an ApplicationManager class for improved modularity and testability, implementing a quadtree spatial partitioning algorithm to reduce computational complexity from O(n²) to approximately O(log n), and expanding Doxygen documentation for clarity. These enhancements strengthened performance, scalability, and maintainability. These skills will be essential for my goal of entering game development.

### - Category 3 Databases: C++ Secure Static Code Artifact

This artifact, based on my CS-405 Secure Coding coursework, focuses on vulnerability mitigation and adherence to SEI CERT C++ standards. I identified and corrected insecure practices such as unchecked input, unsafe type conversions, and improper memory management. Fixes included implementing input validation, verifying stream states, preventing integer overflow, and ensuring proper resource deallocation. This project demonstrates my deep understanding of secure coding principles and my commitment to producing reliable, high-integrity software.

Together, these artifacts form a comprehensive narrative of my growth as a computer scientist. They represent my ability to design interactive software, optimize system performance, and uphold security and ethical coding standards across diverse applications.
